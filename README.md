# Фонд — мультиагентная система для бумажной торговли криптой

Агенты изучают рынок, новости и позиционирование на фьючерсах, спорят о сделке
(адвокаты лонга и шорта, консультант — судья) и предлагают идеи. Все деньги,
размеры и правила риска считает код, модель только рассуждает.
Фаза 1a: **бумага** — реальные сделки не исполняются.

## Где это работает

Всё в облаке, бесплатно, Mac не нужен:

| Что | Где |
|---|---|
| Анализ 2 раза в день (08:07 и 20:07 по Алматы) | GitHub Actions → «Анализ рынка» |
| Команды из Telegram и проверка позиций (каждые 2 ч) | GitHub Actions → «Команды и монитор», раз в час |
| Модель | Groq (основная), Ollama Cloud (запасная) |
| Данные: портфель, сделки, журнал решений, уроки, отчёты | этот репозиторий |

## Первая настройка (один раз)

**Settings → Secrets and variables → Actions → New repository secret:**

| Имя | Что вставить | Обязательно |
|---|---|---|
| `GROQ_API_KEY` | ключ с console.groq.com → API Keys | да |
| `TELEGRAM_TOKEN` | токен от @BotFather | да |
| `OLLAMA_API_KEY` | ключ с ollama.com/settings/keys — запасная модель | нет |
| `TELEGRAM_CHAT_ID` | ваш id в Telegram; если не задан — бот запомнит первого, кто нажал Start | нет |

Перед первым запуском откройте своего бота в Telegram и нажмите **Start**.

## Управление

**С телефона, приложение GitHub:** репозиторий → Actions → «Анализ рынка» →
**Run workflow** → выбрать направление (any / long / short). Отчёт придёт в Telegram.

**Команды боту** (ответ в течение часа):

| Команда | Что делает |
|---|---|
| `/work` | работать по расписанию |
| `/rest` | отдыхать: расписание пропускается, ручные команды работают |
| `/status` | режим, открытые позиции, расход модели за месяц |
| `/run`, `/run long`, `/run short` | анализ сейчас |
| `/check` | монитор позиций: ДЕРЖАТЬ / ПЕРЕСМОТРЕТЬ / ЗАКРЫТЬ |
| `/open C-0001` | записать вход в идею из последнего отчёта (с проверкой по текущей цене) |
| `/close P-0001` | закрыть позицию вручную по текущей цене |

## Файлы

| Файл | Роль |
|---|---|
| `pipeline.py` | один прогон анализа: данные → агенты → риск-движок → отчёт |
| `prompts.py` | инструкции агентов |
| `llm.py` | модели по ролям, переключение при лимитах, учёт токенов и бюджета |
| `market.py` | данные рынка (в облаке — зеркало Binance без блокировки) |
| `context.py` | портфель в промптах, режим рынка BTC, гейты, отсев монет до вызова модели |
| `news.py` | новости из 4 RSS-лент + индекс страха/жадности, проверка ссылок |
| `debate.py` | дебаты лонг ↔ шорт, консультант — судья |
| `derivatives.py` | funding, открытый интерес, перекос лонг/шорт |
| `memory.py` | журнал решений, уроки, разбор отклонённых сетапов, табель агентов |
| `positions.py`, `monitor.py` | бумажные позиции, проверка по свечам, монитор |
| `bot.py`, `notify.py` | Telegram: команды и уведомления |
| `app.py`, `start_panel.command` | панель на Mac (по желанию) |
| `control.json` | режим «работать / отдыхать» |

## Платный режим модели (по желанию)

Если бесплатных лимитов Groq не хватает: подключите оплату в Groq и поставьте
лимит расходов там же. Затем **Settings → Secrets and variables → Actions → Variables**:
`LLM_PAID` = `1`, `LLM_MONTHLY_BUDGET_USD` = например `10`. Расход каждого прогона
пишется в `usage.jsonl` и в конце отчёта.

## Запуск на Mac (по желанию)

```
pip3 install -r requirements.txt
python3 pipeline.py            # анализ, спросит направление
./start_panel.command          # панель в браузере
```
Без ключей в окружении используется локальная Ollama.
